# H4.01 — guía para capturas reales

Toma cada captura en Visual Studio o GitHub durante el procedimiento. Mantén visible el reloj del sistema con fecha y hora reales. No uses capturas editadas, reconstruidas ni generadas.

| Etapa | Qué debe verse |
|---|---|
| Clonación inicial | URL del repositorio personal y carpeta clonada |
| Solución original | Solución y proyecto de consola abiertos en Visual Studio |
| Integración WinForms | Explorador de soluciones con ambos proyectos |
| Interfaz ejecutándose | Menú principal NEXUS abierto |
| Consola preservada | Proyecto de consola seleccionado o ejecutándose |
| Compilación | Resultado correcto de compilación en Visual Studio |
| Commit y push | Commit visible y confirmación de push desde Visual Studio |
| GitHub | Archivos y formularios WinForms en el repositorio publicado |
| Clonación limpia | Nueva carpeta de clonación desde GitHub |
| Ejecución limpia | Solución recién clonada compilada y WinForms ejecutándose |

Reúne las capturas propias en un PDF. Incluye el enlace público al repositorio actualizado.
